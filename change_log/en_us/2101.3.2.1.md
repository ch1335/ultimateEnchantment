# 2101.3.2.1 Update

## Config

- Added a new config option, "ultimateEnchantmentCantBeUpgraded", which controls whether ultimate enchantment levels are locked to the level stored on the item. Enabled by default, preserving the existing behaviour; when disabled, other mods and effects can raise ultimate enchantment levels normally, such as Endersurge from Apotheosis

## Localization

- Completed the localization of the configuration screen, so config entries and sections now display in Chinese/English instead of raw translation keys
- Filled in the missing French translations

## Translation Fixes

- Fixed the French description of the "Hurt Deepens" enchantment, which had the health comparison reversed
