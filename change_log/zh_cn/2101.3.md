# 2101.3 大型更新

## 底层重构

- 几乎完全重构了附魔底层，使用了一套新的附魔注册方式。

## 新增附魔

- 终极猎手:对抗 Boss 时提供伤害与战利品加成，伤害为 (3 x lvl)%，战利品为 (5 x lvl)%，按每件装备的等级分别结算；神化 Boss 同样被视作 Boss
- 堡垒:
- 伤者愈伤:箭命中时，目标当前生命值百分比每比你低 1%，就多造成 1% 伤害，上限为 (10 x lvl)%
- 以太凝矢:箭矢每飞行 1 格附加 (0.1 x lvl) 点伤害，上限 (4 x lvl) 点

## 增强附魔

- 撕裂:提高了按目标当前生命值百分比结算的伤害(0.1%->1%)
- 征服者:取消了有效攻击这个概念，转而使用固定冷却，并且在满层时提供4%的近战吸血
- 背水一战:提高了触发阈值(33.3%->40%)
- 雷霆:提高了第三次攻击对范围内其他目标的伤害((10 x lvl)% -> (25 x lvl)%)

## 削弱附魔

- 碎甲:调整了算法，提供的护甲撕裂不再随着等级线性增加((5 x lvl)% -> (1 - Math.pow(1-0.04,lvl))%)

## 调整附魔

- 生命窃取:降低了生命窃取比例随等级提升的收益((2.5 x lvl)%->(3 + lvl)%),提高了单次回复上限(随着等级提升，最高在4级时达到最大:8%)
- 魔力窃取:降低了魔力窃取比例随等级提升的收益((10 x lvl)%->(4 + 2 x lvl)%),提高了单次回复上限(随着等级提升，最高在5级时达到最大:10%)

## 其他改动

- 现在所有的终极附魔都无法通过常规方式提升等级，比如神化的影激宝石（Endersurge）。
- 添加了一个十分方便的附魔配置方式，并且允许使用 JS 代码行来配置算法。
- 略微降低了部分附魔的等级需求。
